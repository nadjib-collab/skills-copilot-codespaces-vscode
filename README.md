# Copilot PR Setup Repository

This repository is configured for a clean pull request workflow with GitHub Copilot.

## What's included

- Pull request template: `.github/pull_request_template.md`
- Issue forms: `.github/ISSUE_TEMPLATE/*`
- CI workflow on push/PR: `.github/workflows/ci.yml`

## Next steps

1. Create a feature branch.
2. Make your code changes.
3. Open a pull request (template will load automatically).
4. Request Copilot review in your PR flow.
5. Merge when checks pass.
